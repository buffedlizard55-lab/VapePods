A verified price list for **pods that fit a STIIIZY pod pen** (Original / Pro / Pro XL / BAR), for the
94122 area: **STIIIZY Parkmerced (the Stonestown store)**, **Sunset Pipeline on Irving St** and
**Urbana on Geary Blvd**, plus the other SF stores that actually stock STIIIZY-format pods.

Every line lists, separately:

| field | meaning |
| --- | --- |
| **base price** | the number printed on the retailer's own page (and “was” price when the store prints one) |
| **tax status** | `TAX INCLUDED` · `TAX ADDED AT CHECKOUT` · `TAX NOT STATED` — taken from the store's own wording, never assumed |
| **deal** | the promotion the item sits in, quoted from the store's own sale/deal page |
| **source link** | the exact official URL the numbers were read from, for manual verification |
| **date read** | every row is dated; rows not re-read in the latest pass are labelled “not re-checked today” |

## Verification policy (no hallucinations)

1. **Official sources only.** Retailer's own domain (`pipelinedispensary.com`, `bloomerangsf.com`,
   `shop.urbananow.com`, `shop.stiiizy.com`, `stiiizy.com`) or the brand's own ordering domain
   (`stiiizy.dispensary.shop`). One weekly deal comes from STIIIZY Parkmerced's **brand-operated store
   listing** and is labelled as such plus flagged.
2. **Verified means read.** “read 2026-09-15” only ever appears when the page behind the source link was
   fetched and the number read during this pass. Anything older says so.
3. **Tax is never guessed.** No tax note on the page ⇒ `TAX NOT STATED` and the row is treated as pre-tax in
   the estimate.
4. **The estimate is labelled.** Out-the-door figures for pre-tax stores use
   `(price × 1.15) × 1.08625` (CA 15% excise + SF 8.625% sales/use tax, both with official CDTFA links);
   every use of it on the site is marked “est.”.
5. **Flags instead of silence.** Anything that could not be verified cleanly is listed in the site's
   *Irregularities & verification flags* section with the page it was found on.
